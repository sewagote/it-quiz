# IT Quiz

Консольная викторина по IT, написанная на C++. Поддерживает русский и английский языки, выбор категорий и количества вопросов, уровни сложности, систему очков со стрик-бонусом и таблицу рекордов (топ-5).

## Зависимости

- [nlohmann/json](https://github.com/nlohmann/json) — библиотека для парсинга JSON (header-only, лежит в `src/json.hpp`)

## Запуск

1. Собрать проект: `make`
2. Запустить из **корня проекта** (важно — пути к данным относительны корня):
   ```
   ./output/main
   ```
3. Запустить тесты: `make test`
4. Очистить бинарники: `make clean`

> **Важно:** программа ищет JSON-файлы в папке `data/` относительно текущей директории.
> Запускать нужно из корня проекта, иначе данные не загрузятся.

## Возможности

- **Два языка** — русский и английский, строки интерфейса вынесены в JSON
- **Категории** — Сети, Программирование, Аппаратное обеспечение, ОС
- **Гибкий выбор** — можно выбрать несколько категорий и задать количество вопросов в каждой
- **Уровни сложности** — Easy (×1), Medium (×2), Hard (×3); очки зависят от сложности
- **Стрик-бонус** — за 3 и более правильных ответа подряд начисляются дополнительные очки
- **Случайный порядок** — вопросы перемешиваются перед началом теста
- **Объяснения** — при неправильном ответе показывается пояснение
- **Таблица рекордов** — топ-5 результатов с именем, очками и датой, сохраняется в `scores.json`
